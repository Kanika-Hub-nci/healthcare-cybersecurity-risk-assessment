
# Healthcare Cybersecurity Risk Assessment

## Project Overview
A practical Governance, Risk and Compliance (GRC) portfolio project demonstrating cybersecurity risk assessment for a fictional healthcare platform inspired by MediNova AI.

## Objectives
- Identify cybersecurity threats and vulnerabilities
- Assess risk likelihood and business impact
- Develop a cybersecurity risk register
- Recommend risk treatment controls
- Explore ISO/IEC 27001-aligned risk management

## Methodology
1. Identify critical information assets
2. Identify threats and vulnerabilities
3. Evaluate likelihood and impact
4. Calculate and prioritise risks
5. Recommend security controls
6. Document risk treatment recommendations

## Project Status
In progress — risk register and assessment report under development.

## Disclaimer
This project uses fictional scenarios and illustrative risk scores for educational purposes. It is not a formal security audit or certification assessment.
